# F8 host venue: offshore launch barge

The public Bevy demo now accepts `--scene sea`: a small anchored launch barge,
low shore-facing camera, dark water and distant shore lights. The VS Code
**Aestra: Run Fireworks Demo** task selects this scene with the existing
medium-tier variety draft. `--scene calibration` preserves the earlier stage;
the frozen `--showcase` preset rejects the sea override.

The venue belongs to the host. Aestra still owns each rocket's wake, detached
burst, smoke and secondary effects through the same public bindings and saved
editor-ready assets. No boat/water/firework-specific runtime concept was added.

## Launch and scene behavior

- Every rocket starts at a mortar bank on the 13×8-unit barge, at deck launch
  height 2.1. A cabin, deck edge paint, launch tubes and navigation lights provide
  a recognizable launch source.
- The host retargets horizontal launch velocity from each deck mount to the cue's
  original aerial break location. Fuse and vertical launch input remain authored
  host values; ballistic gravity remains authoritative.
- Camera keys 1/2/3 select near, audience and wide shore views. The report runner
  accepts `-Scene sea -Camera sea` and records the venue in its manifest/report.
- Water uses ordinary Bevy PBR lighting and a periodic mipmapped normal texture.
  Root-clock-driven UV drift updates one cached material, with no per-frame
  mesh/image creation, extra VFX owners or reflection-camera simulation. It pauses
  and restarts with the effect clock.
- Art-directed night ambient/moon levels retain dark water and sky. Cabin/shore
  lights are emissive PBR materials. The first gray-water draft inherited too
  much ambient light and is retained as rejected evidence.

This is a first venue draft. It receives ordinary scene lighting but does **not**
mirror the complete firework imagery in the sea. Real spark reflections, more
natural water/shore art and final firework burn realism remain open. Scenery does
not resolve the separate filament/grain quality gap recorded in the gold study.

## Validation

The 56-test demo suite passes, including real host launches from deck mounts,
preserved aerial endpoints, camera HDR/storage checks, source outputs and a water
system regression that verifies pause/restart without advancing playback. Strict
Clippy with the optional audio feature, formatting and runner/task syntax checks
pass. Native medium/low runs and capture/capacity results are recorded in the
[ledger](f8-offshore-2026-10-31.json).

The 128 MiB OIT ceiling remains unchanged; it limits shared fragment storage,
not total VRAM or host scenery allocations. Image lanes include captures/health
work and do not certify a production frame-time budget. The new environment is
a distinct workload/view, not a replacement for the frozen finale's failed gates.

```powershell
cargo run --release --locked -p aestra-demo-fireworks -- --launch-pattern variety --scene sea --tier medium --star-lights --experimental-oit --oit-partitions 4
```
