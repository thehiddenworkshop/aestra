# F5E — bounded independently phased strobe, 2026-10-03

Editable strobe authoring plus the generic material input/runtime handoff it required.
This validates a bounded shell and deterministic off states, not AAA artistry, lower-tier
quality or overlapping-finale throughput. No new simulation trigger or firework-specific API.

## Asset and API contract

`assets/test/effects/fireworks_strobe.aestra.ron` contains five emitters, capacity 306.
Rocket death requests 192 main stars, one flash and 48 smoke particles. Main stars live
three seconds, speed 18–22, with a white-to-gold cooling gradient and exposed HDR radiance.
They are sprite-only: no persistent main-star history fills intentional off intervals.
The launch retains its existing history. Smoke is still an unlit approximation.

`fireworks_strobe_star.aestra.material.ron` calls the reusable custom WESL function
`periodic_gate.aestra.material-function.ron` with phase = normalized age × cycles +
ParticleRandom. Its 18 cycles/life and 18% duty produce 6 Hz at the fixed lifetime.
Both color and alpha are multiplied by the gate: exact zero off, not a dim residual.
Duty is clamped 0..1 in the function. Radiance/cycles/duty use live EffectParameter
bindings; defaults are baked only in the bounded raster test, not the saved workload.
Changing lifetime changes Hertz. The effect finishes at seven seconds including smoke.

Native `ParticleRandom` uses the folded render seed, emitter index and stable spawn ordinal;
it is flat per particle, unrelated to physical/compaction index and independent from
simulation random streams. Sprite/mesh use particle identity, trails their owner and ribbons
the segment's first endpoint. No persistent storage stride or new binding. Unused random
inputs allocate no varying. Expanded custom functions now survive EffectCompiler → runtime
material binding; viewer migration also retains project functions. Authoring FunctionCall
nodes still require their library. Semantic graph analysis and portable shader validation
remain active on the expanded runtime path.

Flashes are material appearance, not particle transitions. No per-flash event/audio route
is added; real audio, voice pooling, choreography and sound policy remain host-owned.

## Native evidence

Ignored local artifacts under `target/fireworks-f5/`. RTX 4070 SUPER / Vulkan, dev build,
960×540, high tier, seed `0xf1e0000000000001`, playback-only, manual 60 Hz, semantic materials,
HDR/Tony/exposure 0/bloom 0.15, authored pixel floors 0/0.

- `f5e-strobe-live.json`: uninterrupted simulation, 120 warm-up / 600 measured frames,
  stable ordering. All three links report demand = accepted **192 / 1 / 48**. Source overflow,
  expansion omission, destination rejection, trail eviction and truncation zero. Peak live
  257; observed history occupancy is zero in the measured window (the rocket's short trail
  precedes it), not proof there is never launch history. Estimated effect buffers 24,592
  bytes, not total device memory; 716 event readbacks. All 600 simulation samples have zero
  checkpoint-capture bytes. Aggregate simulation p50/p95/p99 0.432/0.969/1.023 ms includes
  idle tail and asynchronous sampling. Concurrent local validation shared this GPU; no
  speed comparison, full-frame or finale performance certification follows.
- `f5e-strobe-review/review-manifest.json`: base revision `42c0054a`, dirty source hashes,
  close/audience/wide × eight frames = 24 PNGs, including consecutive frames 110/111/112.
  Native backend, photographic response and all 192 live main stars verified independent
  of the material gate. Endpoint live/occupied/retired/eviction/truncation measured zero at
  frame 420. Inspected close/audience contact sheets show warm sparse dots with changing
  patterns and smoke; insufficient for moving-footage/AAA artistic approval. No goldens approved.
- Required native raster tests independently compare the production identity hash, verify
  exact zero RGB and alpha in off cells, mixed phases, flashes for every star, duty 0/1,
  seed/emitter/ordinal changes, slot reorder and out-of-order/repeated ages. Each of 16 stars
  flashes on 2–4 of 20 ticks at 60 Hz. This deterministic image test proves gates, not
  perceptual stability at arbitrary framerates, temporal AA or arbitrary textures.
