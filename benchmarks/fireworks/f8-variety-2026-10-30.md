# F8 art repertoire: eight-family host sequence

The explicit `--launch-pattern variety` sequence adds 22 uncapped launches across
eight families: point stars, gold tails, cyan rings, amber palms, golden willows,
ruby crossettes, silver crackle and violet strobe. Host cues vary launch position,
direction, height, fuse, grouping and pauses over 16 seconds. The host compiles
the wake/burst catalog once; Aestra owns each firework's particles and secondary
breaks. The ordinary spaced/overlap/finale schedules and frozen v1 assets retain
their behavior.

Six new saved `fireworks_variety_*` assets use generic Ring/Cone/Sphere velocity
distributions, appearance curves, trail history and event-linked secondary births.
Crossette, crackle and strobe reuse earlier authored families with the shared
advected smoke kernel and four exposed smoke controls. These complete shells
are editable in the `assets/test` project, independently of the demo host.
The host adapter now preserves secondary output sources/triggers, rather than
moving all death outputs to the initial flash. Only the removed launch's death
cue is remapped. Native source audits observe crossette/crackle outputs after
tick one, retaining their actual secondary timing. Existing host detonation audio
is unchanged; secondary audio mixing/new recordings remain separate work.

The VS Code **Aestra: Run Fireworks Demo** task now launches the medium variety
draft with selected-star/flash lights, PlaybackOnly and 4×4 experimental OIT.
Use `--showcase` explicitly for frozen v1. The variety runner accepts only
`-Variants tuned`: there is no control/tuned art comparison for this repertoire.
Its first taller flight draft is retained in `target/fireworks-f8/variety-audience-2026-10-30`;
the final willow/gold launch cues keep the crowns farther from the HUD.

## Visual and budget limits

This is an expanded repertoire, **not realism approval**. The user's subsequent
video frames expose the remaining gap: the original gold rendering concentrates
energy into separate heads and ember clusters, whereas the references read as
thin connected cooling spokes. That now takes priority over adding more types.
The separate gold-filament study addresses this one-shell morphology before
propagating changes across the repertoire.

This 22-launch sequence is more spread out than the frozen 32-shell finale.
Its observed capacity passes do not fix or replace the finale's high-tier
fragment failure. Image runs include screenshot/health work; no new production
performance qualification is claimed. Final art, motion/cooling reference review,
secondary sound mixing and wider hardware/view coverage remain open.
